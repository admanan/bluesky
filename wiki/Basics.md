# พื้นฐานและศัพท์

[← กลับหน้าหลัก](Home.md)

## 1. อุปกรณ์

- **สำรับไพ่ Bicycle/Poker 52 ใบ** (ขอบคม ลื่น ไม่โค้งงอ) — ไพ่พลาสติกไม่เหมาะกับท่าฝีมือหลายท่า
- โต๊ะเรียบ ผ้าสักหลาด หรือแผ่นรองไพ่
- กระจกบานใหญ่ หรือกล้องมือถือ สำหรับฝึกดูมุมมองของผู้ชม

## 2. ศัพท์ควรรู้

| ศัพท์ | ความหมาย |
|---|---|
| **Face-up / Face-down** | หงายหน้า / คว่ำหน้า |
| **Top / Bottom card** | ไพ่ใบบนสุด / ล่างสุดของสำรับที่คว่ำอยู่ |
| **Packet / Pile** | กองไพ่ย่อย |
| **Cut** | ตัดสำรับ (ยกกองบนไปไว้ล่าง) |
| **Break** | ช่องว่างเล็ก ๆ ที่เรากันไว้ด้วยนิ้ว (เช่น นิ้วก้อย) เพื่อจำจุดแบ่ง |
| **Force** | การ "บังคับ" ให้ผู้ชมได้ไพ่ใบที่เรารู้ โดยที่เขารู้สึกว่าเลือกเอง |
| **Key Card** | ไพ่ใบที่เราจำไว้เพื่อใช้เป็นหลักอ้างอิงตำแหน่ง |
| **Glimpse** | แอบดูไพ่ใบหนึ่งโดยเนียน |
| **Control** | การพาไพ่ที่ผู้ชมเลือกไปอยู่ตำแหน่งที่ต้องการ (เช่น บนสุด) |
| **Stack** | สำรับที่จัดเรียงไว้ล่วงหน้า |
| **Misdirection** | การเบนความสนใจ |
| **Patter** | บทพูดระหว่างแสดง |

## 3. จับสำรับ: Dealing Grip (ท่ามาตรฐาน)

สำรับคว่ำหน้า วางพาดบนฝ่ามือซ้ายตรงโคนนิ้ว นิ้วโป้งซ้ายวางบนขอบด้านซ้าย นิ้วชี้/กลาง/นาง/ก้อยโอบขอบด้านตรงข้าม ท่านี้เป็นฐานของเทคนิคเกือบทั้งหมดใน wiki นี้

## 4. หลัก 5 ข้อของการแสดง

1. **อย่าทำซ้ำ** กลเดิมกับคนเดิมในคราวเดียว
2. **ทำเหมือนไม่มีอะไร** ท่าลับต้องดูธรรมดาเท่ากับท่าจริง (ผ่อนคลาย ไม่จ้องมือ)
3. **พูดให้มีเรื่อง** ผู้ชมจำเรื่องที่เล่า มากกว่าจำการเคลื่อนไหว
4. **จังหวะ** ทำท่าลับตอนที่ผู้ชมหัวเราะ ขยับ หรือสบตาคุณ
5. **ฝึกหน้ากระจก/กล้อง** แล้วดูย้อนหลังด้วยสายตาผู้ชม

## 5. การฝึกให้ได้ผล

- ฝึก **15 นาที/วัน** ดีกว่า 2 ชั่วโมงสัปดาห์ละครั้ง
- ท่าฝีมือ: **ช้า → ถูก → เนียน → เร็ว** (ห้ามข้ามขั้น)
- ทดลองกับคนจริงเฉพาะเมื่อฝึกจนทำได้ 20 ครั้งติดโดยไม่พลาด
